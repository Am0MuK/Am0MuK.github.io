# am0muk.github.io

Static portfolio page served on GitHub Pages (`Am0MuK/Am0MuK.github.io`) presenting measured empirical findings from two on-chain research projects:
1. **Aave V3 liquidations on Arbitrum One (12 months)**: Market census, profit valuation, liquidator concentration, and time distribution across 11,135 liquidation events.
2. **Uniswap V3 stable-pair LP versus lending (90 days)**: Full tick-level simulation of 1,464 strategy runs across 8 stable pools, comparing active range management against static holding and lending yields.

Every number on the page is generated by offline scripts reading local databases, never typed by hand (with one exception: `data/lpsim_validation.json`, which records on-chain validation ratios requiring archive RPC).

---

## Data Sources

1. **Section A (Liquidations)**:
   - Database: `/data/projects/mev-scout/data/scout365.db` (opened read-only via `file:...mode=ro`).
   - Valuation package: `mev-scout` (`/data/projects/mev-scout/src` with venv `/data/projects/mev-scout/.venv`).
   - Evaluates 11,135 events on Arbitrum One (`chain_id 42161`) between block 380,824,910 and 506,580,201.
   - Runs offline using cached oracle calls from `call_cache`.
2. **Section B (Concentrated Liquidity Simulation)**:
   - Simulation results: `/data/projects/lp-sim/results/2026-09-29/*.json` (1,464 strategy runs across 8 pools x 3 position sizes x 61 strategies).
   - Window: 90 days, blocks 478,933,741 to 509,690,000.
3. **Section B Validation Data**:
   - `data/lpsim_validation.json`: Historical validation ratios against on-chain `feeGrowthGlobal` and liquidity replaying from the [lp-sim README](https://github.com/Am0MuK/lp-sim).

## How to Regenerate

Run the export scripts from the repository root:

```bash
# 1. Export Aave V3 liquidations dataset (writes data/liquidations.json)
/data/projects/mev-scout/.venv/bin/python scripts/export_liquidations.py

# 2. Export lp-sim strategy runs dataset (writes data/lpsim.json)
python3 scripts/export_lpsim.py

# 3. Serve locally to test
python3 -m http.server 8000
```

## Key Findings Summary

- **Liquidations (mev-scout)**: The market generated ~$3.18M net profit across 276 liquidators, but revenue is heavily concentrated in time: the top 5 days accounted for 66.4% of annual profit, and 2025-10-10 alone accounted for 28.8%. Outside crash spikes, monthly market profit averaged ~68,100 EUR across 87 active competitors (median $116 per event). Sub-$100 debt events are net negative after execution costs. Liquidations are won within the same block; latency against incumbents is the binding constraint. Verdict: Do not build.
- **Stable-Pair LP (lp-sim)**: 0 of 1,464 strategy runs met the 15% annual net return kill criterion. Best average net APY across decision pools was 1.76% (USDC/USDT0), 8.93% at $50 / 2.78% at $10k (GHO/USDC), and 2.13% (USDe/USDT0). Active rebalancing (AUTOBALANCER_1) on USDC/USDT0 triggered 403 rebalances in 90 days, losing -$93.78 on $1k and -$628.60 on $10k due to pool fees and price impact. The binding constraint is fee pool depth. Verdict: Do not build.
